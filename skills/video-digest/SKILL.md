# 视频提炼（video-digest）

视频模型看不到连续画面。本技能把视频变成 **少量关键帧 + 一张拼图 + 时间码**，再用 `read_image` 逐张看，最后输出时间轴摘要。**不要**声称自己"看完了整个视频"，你只看了被抽出的离散帧。

## 0. 环境自检（首次使用必做）

1. 找 Python：优先 `DSH_VIDEO_DIGEST_PYTHON` 环境变量，否则 `python` / `py -3` / `python3`。
2. 检查解码库：

```bash
<python> -c "import av, numpy, PIL; print('ok', av.__version__)"
```

- 报 `ModuleNotFoundError: av` → 运行 `<python> -m pip install av`（PyAV 自带 ffmpeg，**不需要**系统装 ffmpeg）。
- 完全找不到 Python → 明确告诉用户需要 Python 3.9+，不要假装抽过帧。

技能基目录：见 `<skill_resources>` 给的路径，脚本在其 `scripts/video_digest.py`。

## 1. 探测元数据

```bash
<python> scripts/video_digest.py info "<视频路径>"
```

拿到时长、分辨率、帧率、音轨。**时长决定下一步参数**；无音轨时不要承诺做字幕。

## 2. 抽关键帧

```bash
<python> scripts/video_digest.py frames "<视频路径>" --samples 120 --shots 9 --out "<输出目录>"
```

| 时长 | samples | shots |
| --- | --- | --- |
| < 2 min | 90 | 9 |
| 2–10 min | 200 | 12 |
| 10–60 min | 400 或分段 | 12–16 |
| > 1 h | 必须分段 `--start/--end` | 每段 9 |

- 输出目录默认 `./video-digest/<文件名>`；给用户一个明确路径，别写进 `C:\Windows` 之类的系统目录。
- `score` 是相邻采样帧的场景变化分（0–1）：高 = 镜头切换/强运动，通常对应关键动作。
- 加 `--json` 可拿到机器可读结果。

## 3. 读图（关键步骤）

1. 先读 `contact_sheet.jpg` 一张图拿到全貌（3 列拼图，每格带时间码）。
2. 需要细节时再逐张读 `frames/*.jpg`（文件名内嵌毫秒时间码）。
3. 读图时记下：**画面里明确出现的文字/UI/人物/物体**，以及**相邻帧之间发生了什么变化**。

## 4. 输出格式

```
## 总览
一句话概括（类型/场景/主体/时长）

## 时间轴
| 时间 | 画面 | 发生了什么 |
| --- | --- | --- |
| 00:00 | … | … |
| 00:06 | … | … |

## 关键点 / 结论
- …
```

硬性要求：

- 每个结论都要能对上某个时间码；**不要编造帧与帧之间的细节**（动作细节、对话内容、被遮挡的内容）。
- 看不清的地方直接说"该段抽帧未覆盖/画面模糊"，不要猜。
- 涉及文字（字幕、UI、PPT）时，尽量逐字转述看到的文字；识别不确定的用 `?` 标注。
- 如果用户要"找某个画面"，用 `--shots` 调大或缩小 `--start/--end` 区间二次抽帧，而不是猜时间。

## 5. 音轨（可选，需要 ASR）

```bash
<python> scripts/video_digest.py audio "<视频路径>" --out "<输出目录>"
```

得到 `audio_16k_mono.wav`。当前若没有 whisper 等 ASR，就说明"只能做画面提炼"，不要伪造字幕。

## 6. 常见问题

- **中文输出乱码**：脚本已自行把 stdout 切到 UTF-8；若宿主仍是 GBK，设置 `PYTHONIOENCODING=utf-8` 或用 `--json`。
- **超长视频**：`--samples` 越大越慢且收益递减；>1 小时先按 10–15 分钟分段，再对感兴趣段细化。
- **超清/超大文件**：seek 会慢，先 `info` 看时长；必要时只处理片段（`--start`/`--end`）。
- **抽出来全是同一画面**（监控、静止讲课）：调大 `--shots`，或用 `--samples` 提高采样密度。
- **没有画面只有声音**：`frames` 会明确报错，转 `audio` 路线。
